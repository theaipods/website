# Unused code and asset cleanup

Audit completed 24 October 2026. This records removals made during this cleanup, separately from deletions already present in the working tree.

## Removed

| Category | Result |
| --- | --- |
| Unreferenced public artwork and starter assets | 20 files; 18,239,771 bytes |
| Temporary QA screenshots, browser logs, scratch scripts and audit output | 429 files; 177,247,188 bytes |
| Unreachable CSS | 1,645 selector entries/branches and 27 unused keyframe definitions |
| Obsolete standalone source files | Five files, listed below |
| Unused declarations | Retired components, exports, imports, types, sample data and inert props removed or made private |

Artwork and temporary files alone reclaim approximately 195.5 MB (decimal). CSS removal also eliminates over 110 KB of unreachable selector rules, in addition to deleted standalone stylesheets. Active artwork, visible layout and the canonical visual-system tokens remain intact.

Deleted standalone files:

- Repository-root `index.html`: disconnected prototype with missing stylesheet references.
- `components/OrchestratorFlow.tsx` and `app/orchestrator-flow.css`: unused component and stylesheet; removed the orphan layout import.
- `app/future-app.css`: unused stylesheet.
- `remotion/Showreel.tsx`: unreferenced duplicate; the active `ShowreelV1.tsx` and registered compositions remain.

Deleted public assets:

- `public/about/workforce/{engineering-agent,finance-agent,research-agent,sales-agent}.png`: exact duplicates of canonical employee artwork.
- `public/brand/homepage-3d/{campaign,custom-pod,feature,industry,ready-team,support}.png`: unused earlier artwork.
- `public/brand/{logo-reference,logo}.png`: unused logo variants.
- `public/event-{approval,enterprise,finance}.webp`: superseded by the active minimal event images.
- `public/{file,globe,next,vercel,window}.svg`: unused starter assets.

Temporary files came from repository-root and `web/` versions of `output/` and `.playwright-cli/`. Their contents were reviewed before deletion.

Automatic approval review blocked directory deletion with the reason `blocked by policy`. Verified temporary files were successfully deleted individually; empty output, browser-log and retired-asset directories remain.

Retired code included unused landing/gallery and pitch sections, old workspace screen components, obsolete catalog samples, redundant Remotion wrappers, dead insurance-section state and timers, hidden motion buttons and an inert employee-image prop. Still-used helpers were made private where appropriate. A reference to the nonexistent `/videos/ai-pods-workflow-demo.mp4` was removed; the existing workflow illustration remains the configured fallback until a real video is supplied.

## How usage was checked

- Traced Next.js route and framework entry points, application imports, CSS imports, scripts, tests and Remotion compositions with Knip and TypeScript.
- Checked public asset references in source, styles, data-driven registries, tool catalogs, documentation and scripts, including dynamically constructed character and icon paths.
- Checked image references in local SQLite and configured PostgreSQL public content (settings, events and speakers), read-only.
- Removed CSS selectors only when their required classes could not be generated by current source; preserved dynamic class patterns and active animations.
- Checked removed artwork against file hashes before deleting. Canonical employee artwork remains available for all 28 registry entries.

No unused-code tool can prove that an arbitrary runtime string or externally configured URL is unused. Framework routes, public content references and manual authoring entry points were explicitly included rather than treating absence of a direct import as sufficient evidence.

## Intentionally retained

Live routes (including all three showreel routes), current employee and footer artwork, tool icons, film audio, Remotion authoring tools, icon/audio generation scripts, documentation, specifications and infrastructure materials remain. Databases, uploads, environment files, editor configuration and migration/setup tools were preserved. Installed dependencies and active build caches are runtime/development infrastructure, not orphan source files.

Existing unrelated modifications and previous deletions in the working tree were not reset or counted as new cleanup work.

## Validation and ongoing checks

- Production build passed and generated all 72 pages.
- Type checking passed with `noUnusedLocals` and `noUnusedParameters` enabled.
- All 49 tests passed, including a new regression check for every registered employee's canonical artwork.
- `npm run audit:unused -- --no-progress` passed with no unused files, exports, dependencies or configuration hints.
- Browser checks passed for 16 public routes at desktop and 390-pixel mobile widths: all returned HTTP 200, with no horizontal overflow or failed local requests.
- Before/after screenshots retained identical page dimensions. Fifteen pages matched exactly; the investor page had a small time-dependent content difference (0.08% of pixels), with no layout change.

Run from `web/`:

```sh
npm run audit:unused
npm run typecheck
npm test
npm run build
```

Knip is pinned and configured in `knip.json`. Supported manual entry points are exposed through `video:studio`, `assets:icons` and `assets:score`. Before future asset deletion, repeat the dynamic-path and persisted-content checks; Knip alone does not determine whether a public image is in use.
