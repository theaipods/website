# Workforce hero background artwork

One generated background plate is used by the independent marketing heroes. No external API, stock search or character generation was used. Outputs were encoded to WebP at quality 88 with Sharp, with no compositional edits. All labels, characters, request bubbles and animated routes are separate website elements.

Only Home uses the supplied office image and requester cutout. The other scenes are independent HTML/CSS/SVG compositions using approved employee PNGs. Unused systems-lab, finance-office and healthcare-office plates from the copied-hero implementation have been removed.

Original generated PNGs remain in the local Codex generated-images directory, session `01a111f3-f8ae-7443-a7b3-b9550af68a25`. Runtime files are committed under `public/brand/`; deployment does not depend on the local generation directory.
