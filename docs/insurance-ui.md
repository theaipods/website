# Insurance solution UI

The Insurance solution page uses `components/InsuranceRedesign.tsx` and scoped `app/insurance-redesign.css`, alongside the shared site header and footer. The page retains six workflows from the existing solution catalog. Tabs switch between local examples; **Try this workflow** animates task-row status only and stops at staff review. The five review stages, evidence checkpoints, and review stages are selectable local illustrations.

The distinct hero opens policy and evidence sheets from a folder, flags a missing detail and prepares a reviewer handoff. Its compliance owl is approved static artwork. The five-stage sequence lasts 5.3 seconds; off-screen, hidden-tab and reduced-motion handling stop automatic playback. Selecting a stage pauses the example; Replay restarts it. See `workforce-story-heroes.md`.

The human-decision boundary stays visible below the hero. Claims, underwriting, coverage, approval, and settlement decisions remain with authorized people. The page does not process real claims, connect policy systems, or execute tasks.
