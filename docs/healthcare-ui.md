# Healthcare solution UI

The page uses HealthcareRedesign.tsx and scoped healthcare-redesign.css with the shared header/footer. Three catalog workflows update the preview; Try this workflow runs a local sequence and stops at Awaiting staff. Five administrative cards and five illustrative responsibility cards support selection. These roles are not registry additions.

HealthcareCoordinationHero in `components/SolutionHeroScenes.tsx` uses a mint appointment station, clock, coordination folio and approved security character. Appointments, Documents and Follow-up buttons change the fictional request, context, schedule and handoff note. The displayed schedule is illustrative, not a booked or available appointment. Five stages complete a 5.3-second loop; manual stage selection pauses and Replay restarts. Off-screen, hidden-tab and reduced-motion handling stop autoplay. There is no visible pause button. The lower workflow, role and administrative examples remain unchanged. See `workforce-story-heroes.md`.

All data is illustrative. No patient records are read, no hospital connection is created, and no diagnosis, treatment or prescription occurs. Staff retain clinical decisions.
