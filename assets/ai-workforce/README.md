# AI workforce artwork

The approved employee artwork consists of 28 individual high-definition transparent PNG illustrations in `public/ai-workforce/avatars-hd/`. The shared `StaticEmployee` component maps stable employee IDs to those images. Keep the supplied species, palette, face and role props intact when using the artwork.

The previous Blender scenes, GLB exports, generated model renders, cropped tile images and their model-generation scripts have been retired. The About hero uses the approved PNGs for its six specialist characters and Three.js geometry only for the Orchestrator machinery, orbital pod platforms, lighting and energy routes.
